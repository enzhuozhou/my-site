How does it work?

A very silly invention.

The goal is simple: turn the machine ON. But it does not want to stay on, so it reaches out and turns itself OFF.

  1. Press the switch.
  2. Watch the little arm react.
  3. The machine switches itself off automatically.
  4. Try again... if you like.

What I practiced: event listeners, variables, changing HTML attributes, CSS animation, and setTimeout().

This is a browser simulation: no real hardware required.
